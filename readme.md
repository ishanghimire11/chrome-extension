# SuggestPass - Password Suggestion Chrome Extension

**SuggestPass** is a lightweight and user-friendly Chrome extension for generating secure passwords directly in your browser. It allows you to customize your password's length and complexity, ensuring both security and convenience.

---

## Features

- **Password Length Control**: Adjust the length of the password with an intuitive slider (default: 18 characters).
- **Customization Options**: Toggle the inclusion of:
  - Uppercase letters
  - Lowercase letters
  - Numbers
  - Special symbols
- **Instant Password Generation**: Generate a password with a single click.
- **Responsive UI**: Sleek and modern design for seamless user experience.

---

## Installation

1. Clone or download this repository.
2. Open Chrome and go to `chrome://extensions/`.
3. Enable **Developer Mode** (top-right corner).
4. Click **Load Unpacked** and select the folder containing this project.
5. The **SuggestPass** extension icon will appear in your Chrome toolbar.

---

## Usage

1. Click the **SuggestPass** icon in your Chrome toolbar to open the extension popup.
2. Customize your password preferences:
   - Adjust the length using the slider.
   - Toggle options for uppercase, lowercase, numbers, and symbols.
3. Click the **Generate** button to create a password.
4. The generated password will appear in the text field at the top of the popup.

## How It Works

The extension uses JavaScript to dynamically generate random passwords based on your selected criteria. It adheres to Chrome's **Manifest V3** requirements for improved security and performance.
